# @leofdss/doyen

> 🚧 **Not usable yet.** Version 0.0.1 only reserves the name.

Pick one master among the instances of a service, through the database you already run. The
oldest live instance is the master; when it dies, the next in line takes over. Redis first,
then PostgreSQL and MongoDB.

Follow the project on GitHub: https://github.com/leofdss/doyen
