## Claude Code specifics

- The OpenSpec workflows are the slash commands `/opsx:propose`, `/opsx:explore`,
  `/opsx:apply`, `/opsx:update`, `/opsx:sync` and `/opsx:archive` (`.claude/commands/opsx/`),
  with the matching skills in `.claude/skills/openspec-*`. Both are generated by
  `openspec init` / `openspec update` (OpenSpec 1.15.0).
